\section{Related work}
\label{sec:related}

We organize prior work by the claim it already occupies. We do not treat the search as an exhaustive systematic review. On 26~September 2026, Semantic Scholar's API returned HTTP 429, and Scopus was not queried. OpenAlex full-text search over 2024 onward was noisy. The papers below are ones we retrieved and read far enough to place. Two further retrieved papers, on guarded query routing, on a preference platform for LLM routers, and on latent-task prompt routing, are listed in the bibliography and are not part of the comparison in this section~\citep{sleher2025,lai2026,zhang2026finerouter}.

\paragraph{Algorithm selection.}
Rice~\citeyearpar{rice1976} formulates selection as a map from problem features to algorithm performance. Smith-Miles~\citeyearpar{smithmiles2009} surveys that map as meta-learning across disciplines. Work that uses task features to predict which procedure will perform well falls within this broader framework. Our primitive set is not that survey's portfolio. The general algorithm-selection formulation is therefore not claimed as a contribution of this pilot.

\paragraph{Routing among language models.}
{\emergencystretch=3em
Shnitzer et al.~\citeyearpar{shnitzer2023} train routers on benchmark datasets and apply them to a new task. The router uses embeddings of the new task's inputs. GraphRouter~\citep{feng2024} represents tasks, queries, and LLMs in one graph, predicts performance and cost, and then applies a user preference. TRouter~\citep{liu2026trouter} uses synthesized task profiles for cold-start routing among LLMs. LLMRouterBench~\citep{li2026llmrouterbench} re-evaluates a large set of LLM routers and reports that many of them do not reliably outperform a simple baseline, with a remaining gap to an oracle. RouteLLM, Hybrid LLM, RouterBench, and FrugalGPT select among generative models at query level~\citep{ong2024,ding2024,hu2024,chen2023}. Those systems are neighbors. Their action is to choose which language model to call. This pilot instead includes procedures that need not generate text.
\par}

\paragraph{Encoder or classifier versus a generative classifier.}
TaMAS uses a manual task taxonomy to characterize differences in the relative performance of BERT-like models and LLMs on text-classification tasks; it does not train a held-out selector~\citep{zhang2025tamas}. Other studies compare fine-tuned encoders, linear models, or logistic regression with zero-shot or few-shot generative models and, in some cases, report latency and dollar cost~\citep{bucher2024,edwards2024,vajjala2025,gonzalez2026}. Cascades that send uncertain classifier outputs to an LLM use a signal that exists only after a model has run~\citep{deandrade2024,abedini2025,kondadadi2026}. Repeating the finding that a trained classifier can outperform a prompted LLM on a fixed label set would not be a new result. We cite these studies rather than treating those established comparisons as new results.

\paragraph{Dataset-level meta-learning.}
Bino and Shrivastava~\citeyearpar{bino2026} extract meta-features from the training split of summarization datasets and use leave-one-dataset-out to predict which pretrained summarizer attains the higher score under a stated metric. Among the retrieved literature, this is the closest methodological precedent: features available without the test set, and the dataset as the holdout unit. Their candidates are abstractive summarizers. They predict a selected system under one metric. They do not predict a vector that includes an invalid-output rate, and they do not include a rule, a conventional text classifier, a typed decision model, and a generative decision model together.

\paragraph{Typed decision models and output constraints.}
Laya is an open decision-model checkpoint~\citep{laya2026}. Public descriptions of Jev and Decision~1.0 treat typed decisions as a software interface~\citep{liu2026decision,li2026jev}. We use Laya as one pinned implementation. We do not treat vendor numbers as results. Separately, constrained decoding can remove structural schema failures of small generative models~\citep{chavan2026}. Our generative pin does not use that constraint. The invalid-output rates below are rates under exact string match, not rates under grammar-constrained decoding.

Within the literature retrieved for this study, we found no paper that trains on a fixed pre-deployment fingerprint and predicts the seven-coordinate profile of a rule, a TF-IDF logistic regression, Laya, and Qwen2.5-0.5B-Instruct under family holdouts and an e-commerce holdout. This is a statement about the sources we obtained. It is not a claim that the experiment is absent from every index, and it is not a claim of priority.
