When a system must make a bounded decision, the task can be implemented using a rule, a conventional classifier, a typed decision model, or a generative language model. These primitives can differ substantially in quality and operational behavior. A natural question is whether measurable properties of the task, fixed before any primitive is evaluated, can predict those outcomes on an unseen task.

We report an eight-task pilot that freezes the task set, task fingerprint, primitive implementations, and prediction specification before the predictive results are observed. The target is a seven-coordinate profile comprising macro-F1, local training time, local inference time, API cost, p50 and p95 per-example latency, and invalid-output rate. The predictor uses ridge regression with penalty~1 for the learned coordinates; API cost is fixed at zero, and training-time prediction is fit only for the classifier. The baseline is the training-fold mean profile of each primitive. ESCI is held out as a single e-commerce task, while the remaining holdouts remove task families.

Across the measured task--primitive pairs, quality and validity vary substantially by primitive and task. Under the pinned Qwen2.5-0.5B configuration, the invalid-output rate ranges from 0.023 on VitaminC and 0.025 on SMS Spam to 1.000 on Civil Comments, where every output violates the one-label contract and macro-F1 is therefore 0. The ridge predictor is closer than the primitive-mean baseline on macro-F1 for 5 of 8 held-out tasks and on invalid-output rate for 2 of 8. Under every vector policy, both predictors select the TF-IDF logistic-regression classifier. On the ESCI holdout, macro-F1 prediction error decreases from 0.2825 to 0.1024 and invalid-rate error from 0.1199 to 0.0444, without changing the selected primitive.

These eight tasks do not establish whether task fingerprints are generally predictive, whether one primitive is generally preferable, or whether the reported latency is a hardware-normalized measure of speed. They also do not establish that the study has introduced a validated router. Rule, classifier, and Laya measurements were obtained on CPU; Qwen was measured on a GTX 1650 Ti in float16. API cost is zero because no API was called. Semantic Scholar returned HTTP 429 during the literature screen, and Scopus was not queried.
